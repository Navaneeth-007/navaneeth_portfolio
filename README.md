# 🚀 Navaneeth's Portfolio

A modern and responsive portfolio website showcasing my journey as an **AI/ML Engineer** and **Data Scientist**. Built with React, the portfolio highlights my research, AI projects, technical expertise, and professional experience through an interactive and clean user interface.

## 🌟 Features

- Modern and responsive design
- Interactive project showcase
- Experience timeline
- AI/ML focused portfolio
- Technical skills visualization
- Research & achievements section
- Contact form powered by EmailJS
- Resume download
- Smooth animations and transitions
- Mobile-friendly interface

## 🚀 Run Locally

Clone the repository

```bash
git clone https://github.com/Navaneeth-007/portfolio-website.git
```

Navigate to the project

```bash
cd portfolio-website
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```

Build for production

```bash
npm run build
```
